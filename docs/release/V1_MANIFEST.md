# AkshaConnect V1 — Phase 0 Foundation Manifest

Version: `0.1.0-phase0`

## Purpose

Establish the standalone repository as a runnable, testable receiving product before extracting live collaboration code from AkshaERP.

## Included

- Repository/workspace baseline
- Health/readiness API
- CI
- Docker
- Syntax/test verification
- ERP event contract V1
- Current-state audit
- Extraction boundaries
- Authentication/tenant boundary
- Phase 0 acceptance document

## Explicitly excluded

- Production React UI extraction
- React Native app shell
- Production database migration
- Direct AkshaERP database access
- ERP approval/workflow implementation
- CHUB replacement
